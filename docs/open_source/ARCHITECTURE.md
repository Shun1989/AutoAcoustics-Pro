# 架构与计算说明

`src/autoacoustics` 是产品源码。`acquisition` 管理声卡/NI/文件交接及完整落盘；`importers` 统一输入与通道单位；`analysis` 计算；`ui` 提供 Qt 工作台；`knowledge` 管理本机资料与问答；`jobs.py` 在独立工作进程执行耗时任务。`report.py`、`batch.py`、`project.py` 分别处理报告、批量和结果快照。

## 单位与校准

输入统一为通道×样本数组，保留原采样率、单位及来源哈希。FS/V 需要显式换算才能成为 Pa；已经声明 Pa 的支持格式不因传感器元数据再次乘灵敏度。校准记录包含适用来源与配置，校准不能移用于不同增益或不匹配的录音。

## 计算定义

- FFT 是单边峰值幅度谱，按窗相干增益归一，DC/Nyquist 不加倍。补零只改变频点间隔。PSD 按 `fs × sum(window²)` 归一，Welch 使用独立段长。
- STFT 不在录音两端补零，时间取原事件窗中心。短事件无可用图时给出原因。显示抽取不会改变原分析数组与导出指标。
- LZeq 以事件内 Pa² 平均及 20 µPa 为参考。LAeq 对 A 计权后的声压求能量平均。Fast/Slow 时间常数为 0.125/1 s，滤波从录音起点连续运行，事件切分不重置状态。
- 1/3 倍频程使用 base-10 频带及连续 SOS 滤波；有效上边界受采样带宽约束。滤波启动工程参考不代表 IEC 等级认证。
- 响度固定使用 MoSQITo 1.2.1 模型。时变算法内部使用 48 kHz，有理重采样保留原时间轴；低于 48 kHz 的带宽限制明确标记。稳态与时变结果分别呈现。
- A/B 差值为 B−A。单位不同、缺失或无有效差值时不伪造数值；未知工况不自动解释为故障原因。
- 手动 RPM 的频率/阶次参考基于恒速假设。实测 RPM CSV 必须覆盖所选音频区间；角域分析使用抗混叠处理，结果保留所用来源与假设。

## 验证层级

合成信号验证已知幅值、能量、时间轴、异常输入、来源及工作流程。与固定上游算法对照验证编排一致性。外部数值参考、独立声校准、真实硬件计量链和首次使用者验收各自独立，公共测试不能替代这些关口。

原规格包含原产品的 EoL、ODS、PHM 和企业模块，本次重实现按用户要求排除。HEAD 官方受控录制仍需准确设备、许可和 SDK 接入。
